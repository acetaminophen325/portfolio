My Projects

Here are some of the projects I’ve worked on.

Featured Projects

  • The Intelliscope

    With a group of Biomedical Engineering undergraduate researchers at UCI, we redesigned a traditional otoscope using SolidWorks. Every part, excluding the lenses and electronic components, were replaced using 3D-printed filaments, and an ESP microcontroller was integrated to the product. Overall, our final prototype was awarded for its improvements to flexibility and cost-effectiveness.

  • Glaucoma Detection System

    Using MATLAB, I created an image processing pipeline with filtering, thresholding, and object identification, all which possess machine learning capabilities, for early diagnosis using MRI images. This code achieved 92% accuracy in identifying patients with glaucoma during preliminary testing.

  • Medical Device Cost Analysis

    I developed a MATLAB model to optimize production costs for prosthetic limbs, reducing manufacturing expenses by 18% while maintaining quality standards.
